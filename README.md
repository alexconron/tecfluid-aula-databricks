# Curso de Databricks para Tecfluid

Sitio estático con la carta Gantt, el programa de ocho clases y los materiales de práctica.

Abre `dist/index.html` en el navegador. No se requieren dependencias ni compilación.

- `dist/index.html` contiene el cronograma y el programa.
- `dist/style.css` define el diseño.
- `dist/materiales/` contiene el CSV ficticio, el notebook y los apuntes.
- `dist/ejemplo-carga.yaml` es la plantilla ilustrativa.
