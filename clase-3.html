¿Qué parte del YAML cambia al agregar una consulta?

Abre el YAML de Nicolás. ¿Qué cambiarías para traer otra consulta del mismo sistema?

sap
Indica dónde busca el notebook la conexión a SAP.
bronze
Declara catálogo y esquema. En Settings del pipeline se confirma el destino efectivo.
sources
Contiene un bloque por fuente. Cada guion inicia una entrada.

Dentro de una fuente

nombre
Define el nombre de la tabla de salida.
query
Contiene el SQL que se ejecuta en SAP HANA. Con >- podemos escribir este SELECT en varias líneas.
activo
Con false, el pipeline omite esa fuente en su ejecución.

El notebook lee el SQL en HANA y genera una tabla Delta. Muestra en qué catálogo y esquema quedaría tu nombre si se habilitara para el piloto.
