COPY INTO · Carga por lotes con SQL

En cada corrida incorpora los archivos nuevos a una tabla Delta. Por defecto omite archivos que ese comando ya cargó a la misma tabla.

Auto Loader · Archivos nuevos en una carpeta

Detecta archivos nuevos y guarda el progreso con un checkpoint. Úsalo cuando seguirán llegando entregas a la misma ubicación.

Documentación de Auto Loader ↗

Lakeflow · Conectar, definir y ejecutar

Lakeflow Connect
Conectores administrados para orígenes compatibles, como aplicaciones y bases de datos.
Lakeflow Spark Declarative Pipelines
Define tablas y transformaciones en SQL o Python. Un pipeline puede usar Auto Loader para incorporar archivos nuevos.
Lakeflow Jobs
Coordina tareas, como ejecutar un notebook o iniciar un pipeline, y registra el resultado de cada ejecución.

Documentación de Lakeflow Connect ↗

Una tabla incremental con Lakeflow

Dentro de un pipeline SQL, STREAM read_files usa Auto Loader para alimentar una tabla de streaming.
